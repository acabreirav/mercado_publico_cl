Cada fila es un producto comprado por varios organismos del Estado. La franja muestra cuánto varía el precio unitario que pagó cada uno. Ordenado por lo que más vale investigar: mucha diferencia de precio entre muchos compradores. Haz clic para abrir el detalle hasta la orden de compra.

Lo que más llama la atención

Productos de alta confiabilidad (muchos organismos) con la mayor brecha de precio. Clic para ver el detalle.

Cómo leerlo. Es una señal para investigar, no una acusación. La API de órdenes de compra no informa la unidad de medida, así que dos compras del mismo código pueden diferir por envase o cantidad, no solo por sobreprecio — por eso se excluyen los casos con dispersión implausible. La confiabilidad sube con el número de organismos y de compras. Universo: muestra de órdenes de compra (mayoría 2024), no todo el gasto del Estado.
