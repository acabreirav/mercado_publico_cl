El mismo producto, a precios muy distintos

Cada fila es un producto comprado por varios organismos del Estado. La franja muestra cuánto varía el precio unitario pagado por cada uno. Haz clic para abrir el detalle hasta la orden de compra concreta.

Cómo leerlo. Esto es una señal para investigar, no una acusación. La API de órdenes de compra no informa la unidad de medida, así que dos compras del mismo código pueden diferir por envase o cantidad, no solo por sobreprecio — por eso se excluyen los casos con dispersión implausible. Universo: muestra de órdenes de compra (mayoría 2024), no todo el gasto del Estado.
